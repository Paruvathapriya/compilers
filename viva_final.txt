2)SDT for Binary to Decimal Conversion
S → B              { S.val = B.val; }

B → B₁ D            { B.val = B₁.val * 2 + D.val; }

B → D               { B.val = D.val; }

D → 0               { D.val = 0; }

D → 1               { D.val = 1; }

6)l attribute, s attribute

SDD / SDT

1. Attribute Grammar

SDD → Syntax Directed Definition
SDT → Syntax Directed Translation

S-Attributed
- Uses only synthesized attributes.
- Attributes are calculated from child nodes.

Example:
A → BCD
A.s = f(B.s, C.s, D.s)

L-Attributed
- Uses both synthesized and inherited attributes.
- Inherited attributes can be passed from parent to child and from left siblings.

Example:
A → BCD
C.i = A.i
D.i = B.s
A.s = f(B.s, C.s, D.s)

Can use both inherited and synthesized attributes.
