1\. Header files

First, we include the required header files for printing output and handling strings. We also declare the Lex function and the error-handling function.

2\. TAC structure

Here, we create a structure to store the result, operands, and operator of each instruction. The array stores the generated instructions.

3\. Generate function

This function creates Three Address Code for arithmetic operations. It creates temporary variables like `t1` and `t2`.

4\. Emit function

This function stores assignment statements. For example, `a = t1`.

5\. Output function

This function prints the original TAC, optimized TAC, and target code.

6\. Code optimization

This part simplifies arithmetic operations when both operands are numbers. For example, `t1 = 3 * 4` becomes `t1 = 12`.

7\. Target code generation

This part converts the TAC into simple target instructions like `MOV`, `ADD`, `SUB`, `MUL`, `DIV`, and `STORE`.

8\. Union declaration

The `%union` stores token values as strings, such as identifiers and numbers.

9\. Token declaration

The `%token` declaration defines `ID` for identifiers and `NUM` for numbers.

10\. Type declaration

The `%type` declaration specifies that expressions, terms, and factors carry string values.

11\. Program rule

This is the starting rule. If the input is correct, it prints `Syntax Correct` and calls the output function.

12\. Statements rule

This rule allows us to enter one or more statements.

13\. Statement rule

This rule checks assignment statements in the format `a = expression;`.

14\. Expression rule

This rule handles addition and subtraction.

15\. Term rule

This rule handles multiplication and division. These operations have higher precedence than addition and subtraction.

16\. Factor rule

This rule recognizes numbers, identifiers, and expressions inside parentheses.

17\. Error-handling function

This function prints an error message if the input syntax is incorrect.

18\. Main function

The main function starts the program by calling `yyparse()`, which reads the tokens from Lex and checks the input.

### Expression rule

```
expr:
      expr '+' term { $$ = generate($1, '+', $3); }
    | expr '-' term { $$ = generate($1, '-', $3); }
    | term          { $$ = $1; }
    ;
```

This rule handles addition and subtraction in an expression.

- The first line handles addition. It calls the `generate()` function to create TAC for the addition.
- The second line handles subtraction. It calls the `generate()` function to create TAC for the subtraction.
- The third line passes the value of `term` to `expr` when there is no addition or subtraction.

Here, `$1` represents the first value, `$3` represents the third value, and `$$` stores the result of the expression.

Example: If the input is `a = 5 + 3;`, the expression rule calls `generate("5", '+', "3")` and produces:

```
t1 = 5 + 3
```

In simple words, the expression rule identifies addition and subtraction and generates the corresponding Three Address Code.
